Entry for make.fun's "Sum up 17 November's world news in one image" bounty ($250 in USDC).
The program writes one image to `/output/entry.png`: a one-page newspaper,
"THE WORLD IN ONE DAY — Tuesday, 17 November 2026 · 35 stories · 6 continents",
led by the Kerch Bridge collapse, the US strike on Qeshm Island and Nvidia's
record quarter, with a world map marking where the biggest stories happened and
numbered stories 4–35 across every region and field. All text is drawn
procedurally, so nothing in the image can garble, and the program needs no
network and writes the exact same bytes on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
